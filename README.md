# 📊 Dashboard Interativo em Python

Um dashboard web interativo desenvolvido em **Python** utilizando **Dash**, **Plotly** e **Pandas** para visualização de dados de vendas por meio de gráficos dinâmicos.

## ✨ Funcionalidades

- Leitura de dados a partir de um arquivo CSV
- Dashboard web interativo
- Gráficos dinâmicos
- Seleção de diferentes tipos de gráficos
- Visualização de vendas por produto
- Atualização dos gráficos em tempo real

## 🛠️ Tecnologias

- Python 3.x
- Pandas
- Plotly
- Dash

## 📦 Instalação

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/dashboard-interativo-python.git
cd dashboard-interativo-python
```

Instale as dependências:

```bash
python -m pip install -r requirements.txt
```

## ▶️ Executando o projeto

Inicie a aplicação com:

```bash
python app.py
```

Após iniciar, acesse no navegador:

```
http://127.0.0.1:8050
```

## 📁 Estrutura do projeto

dashboard-interativo-python/
